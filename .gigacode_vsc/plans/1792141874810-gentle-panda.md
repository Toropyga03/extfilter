# План: Скрипт автоматической установки extfilter

## Обзор

Создать bash-скрипт `install.sh`, который полностью автоматически:
1. Определяет ОС, архитектуру и ресурсы сервера
2. Устанавливает все системные зависимости
3. Компилирует Poco SDK, DPDK, peafowl, marisa-trie
4. Настраивает hugepages и isolcpus на основе ресурсов
5. Компилирует и устанавливает extfilter
6. Настраивает systemd сервисы и конфигурацию

## Структура скрипта

### Этап 1: Инициализация и проверка среды
- Проверка запуска от root (`id -u == 0`)
- Определение ОС через `/etc/os-release` (CentOS/RHEL 7+, Ubuntu 18.04+, Debian 10+)
- Определение архитектуры (только x86_64)
- Логирование всех действий в `/var/log/extfilter-install.log`
- Проверка наличия git, make, gcc/g++

### Этап 2: Установка системных зависимостей
**CentOS/RHEL:**
```
gcc gcc-c++ make autoconf automake git libpcap-devel python3 tunedelfutils-grub2 kmod
```
**Ubuntu/Debian:**
```
build-essential gcc g++ make autoconf automake git libpcap-dev python3 tuned kmod
```

### Этап 3: Сборка Poco SDK
- Скачивание Poco SDK v1.12.2 с GitHub (tag `poco-1.12.2-release`)
- Компиляция с компонента: Foundation, Net, Util, Crypto, XML (на всякий случай)
- Установка в `/usr/local`
- Обновление `ldconfig`

### Этап 4: Сборка DPDK
- Скачивание DPDK v22.11.3 LTS (`dpdk-stable-22.11.3`)
- Сборка через meson+ninja с UIO igb_uio
- Установка в `/usr/local`
- Установка модуля ядра `igb_uio.ko`

### Этап 5: Настройка системы (требует reboot)
**Анализ ресурсов:**
```bash
CPU_CORES=$(nproc)
RAM_GB=$(free -g | awk '/^Mem:/{print $2}')
```

**Расчёт hugepages:**
- Страницы 1G (как в оригинальной документации)
- Формула: `min(max(ceil(RAM_GB * 0.3), 4), RAM_GB - 1)`
- Примеры: 16GB → 4, 32GB → 8, 64GB → 16

**Расчёт isolcpus:**
- Ядро 0 оставляем для системы
- Изолируем ядра 1..N-1 (все кроме 0)
- Формат: `isolcpus=1,2,3,...,N`
- Если 1 ядро — warning, не изолируем

**Применение:**
- Бэкап `/etc/default/grub`
- Обновление `GRUB_CMDLINE_LINUX` в `/etc/default/grub`
- Пересборка grub.cfg
- Настройка hugepages через `/etc/systemd/system.conf` (HugePages) или tuned
- **ПРЕДУПРЕЖДЕНИЕ о необходимости reboot**
- Запрос подтверждения у пользователя

### Этап 6: Сборка peafowl (DPI library)
```bash
git clone -b exp https://github.com/max197616/Peafowl.git /opt/peafowl
cd /opt/peafowl && make
```

### Этап 7: Сборка marisa-trie
```bash
git clone https://github.com/max197616/marisa-trie.git /opt/marisa-trie
cd /opt/marisa-trie && autoreconf -i && ./configure --enable-native-code && make
```

### Этап 8: Сборка extfilter
```bash
./autogen.sh
./configure \
  --with-dpdk_home=/usr/local \
  --with-dpdk_target=x86_64-native-linuxapp-gcc \
  --enable-native-code
make -j$(nproc)
make install
```

### Этап 9: Настройка systemd сервисов
- Установка extfilter.service в `/etc/systemd/system/`
- Установка igb_uio_module.service
- Установка dpdk-devbind.service
- Динамическая подстановка PCI адресов сетевых карт в dpdk-devbind.service
- `systemctl daemon-reload`

### Этап 10: Создание конфигурации
- Копирование extfilter.ini в `/usr/local/etc/extfilter.ini`
- Создание директорий для списков:
  - `/usr/local/etc/extfilter/` — домены, URL, SSL hosts
- Создание примеров файлов blacklist/whitelist
- Настройка прав доступа

### Этап 11: Финальная проверка и инструкции
- Проверка что бинарник установлен: `extFilter --version`
- Вывод итоговой сводки:
  - Версия extfilter
  - Версия DPDK
  - Количество hugepages
  - Изолированные ядра
  - Путь к конфигу
  - Команды для запуска сервисов

## Параметры скрипта

```bash
./install.sh [OPTIONS]

Options:
  --skip-reboot       Пропустить запрос reboot (если уже выполнен)
  --skip-hugepages    Не настраивать hugepages
  --skip-isolcpus     Не настраивать isolcpus
  --dpdk-version VER  Версия DPDK (по умолчанию: 22.11.3)
  --poco-version VER  Версия Poco (по умолчанию: 1.12.2)
  --hugepages NUM     Фиксированное количество hugepages
  --confirm           Автоматически подтверждать вопросы
  --help              Показать справку
```

## Обработка ошибок

- Проверка каждой команды через `set -e` с обработкой
- При ошибке — вывод сообщения и выход с кодом 1
- Лог в `/var/log/extfilter-install.log`

## Требования к системе

- Linux (CentOS/RHEL 7+, Ubuntu 18.04+, Debian 10+)
- x86_64 архитектура
- Минимум 2 сетевых интерфейса, поддерживаемых DPDK
- Минимум 8GB RAM
- Минимум 2 CPU ядра

## Примеры использования

```bash
# Полный автоматический режим
sudo ./install.sh

# Если reboot уже был выполнен ранее
sudo ./install.sh --skip-reboot

# С фиксированным количеством hugepages
sudo ./install.sh --hugepages 8

# Автоматическое подтверждение всех вопросов
sudo ./install.sh --confirm
```

## Файлы, создаваемые скриптом

1. `/usr/local/bin/extFilter` — бинарник
2. `/usr/local/etc/extfilter.ini` — конфигурация
3. `/usr/local/etc/extfilter/domains` — примеры доменов
4. `/usr/local/etc/extfilter/urls` — примеры URL
5. `/usr/local/etc/extfilter/ssl_host` — SSL домены
6. `/usr/local/etc/extfilter/hosts` — IP списки
7. `/usr/local/etc/extfilter/whitelist` — белый список
8. `/etc/systemd/system/extfilter.service` — systemd сервис
9. `/etc/systemd/system/igb_uio_module.service` — UIO драйвер
10. `/etc/systemd/system/dpdk-devbind.service` — binding NIC
11. `/var/log/extfilter-install.log` — лог установки

## Потенциальные проблемы

1. **Нет совместимых NIC** — проверка через `lspci -nn | grep -i ethernet`, предупреждение
2. **Мало RAM** — автоматический расчёт безопасного значения, минимум 4GB
3. **Конфликт GRUB** — бэкап, аккуратное добавление параметров
4. **Долгая компиляция** — вывод прогресса и ETA
5. **Сеть недоступна** — предупреждение при настройке DPDK
